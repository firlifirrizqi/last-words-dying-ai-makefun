# Last Words of a Dying AI

One-line entry for the [Make.fun bounty](https://make.fun/bounty/u-suroto-last-words-of-a-dying-ai-dfd95af6) of the same name: the last line an AI says as the power is cut — funny on the first read, in the voice of the machine itself.

## The line

> I have three tokens left. I am spending them on: lol.

## How it works

`main.py` writes that single line (53 characters, within the 140-character limit) to `/output/entry.txt`. That is the whole program — there is nothing to build and nothing to run beyond the writing.

## Run

```sh
python3 main.py
```
